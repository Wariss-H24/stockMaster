# StockMaster Frontend

Simple Vue 3 + Vite frontend for the StockMaster backend.

Quick start:

1. Install dependencies:

```bash
cd frontend
npm install
```

2. Run dev server (will proxy `/api` to `http://localhost:8080`):

```bash
npm run dev
```

3. Open http://localhost:3000

Notes:
- The backend must be running on port 8080 for the proxy to work.
- This is a minimal scaffold; feel free to improve UI, add state management, and validations.
